# Harvest Ledger

A web tool for coffee receiving stations to register deliveries, calculate
payment automatically, and print receipts. Built with PHP and HTML/CSS.
No database: data is kept in the session and can be exported to a JSON or CSV file.

## Requirements
- PHP (via XAMPP)
- Apache (via XAMPP)

## How to run
1. Copy the project folder into `C:\xampp\htdocs\`.
2. Start Apache in the XAMPP Control Panel.
3. Open `http://localhost/HarvestLedger/index.php` in your browser.
